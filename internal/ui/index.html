Открытие счёта.
От заявления до записи в АБС.

Один банковский кейс, восемь связанных процессов. Проверки выполняются параллельно, сотрудники работают с переменными задач, а отдельная мок-АБС переживает повторы команд.

Только учебный пример. Это не банковская система и не юридическая рекомендация. Реальные счета не открываются. Авторы не несут ответственности за решения, принятые на основе примера, и последствия его использования. Используйте только вымышленные данные.

01 / ПРИЁМ

Заявление и идентификация

Переменные анкеты, подтверждение проверки личности, возврат за недостающими сведениями.

 02 / ПРОВЕРКИ

Три проверки одновременно

Документ, перечни и налоговые сведения. Решение DMN выбирает следующий шаг.

 03 / РАССМОТРЕНИЕ

Сотрудник и руководитель

Разрешение совпадения, обоснование решения, второй сотрудник и эскалация по таймеру.

 04 / ДОГОВОР

Подписание или отказ клиента

Фиксация учебного подтверждения. Отказ клиента не превращается в отказ банка.

 05 / МОК-АБС

Один запрос — один счёт

Идемпотентность, потерянный ответ, ожидание и сверка регистрационной записи.

 06 / ПОСТОБРАБОТКА

Досье, ФНС и уведомление

Учебные интеграции. Повтор отправки не отменяет уже открытый в мок-АБС счёт.
Сценарий: совершеннолетний гражданин РФ, личное обращение, текущий счёт в рублях. RS-Bank — предметный ориентир; реальный API поставщика не используется. Документация API go-bpm.
