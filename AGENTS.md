# GoBpmBank

Самостоятельный учебный пример открытия счёта на go-bpm. Документация, комментарии и сообщения коммитов — по-русски.

- Не изменять соседние репозитории go-bpm, go-bpm-site и go-bpm-modeler.
- BPMN/DMN — источник процессов. Перегенерация: `go generate ./...`. Файлы с `Code generated` руками не менять.
- Не добавлять базовые процессы Test* из демонстрации движка.
- Не использовать реальные персональные данные. Не выдавать mock-core-banking за API RS-Bank.
- Сохранять учебную оговорку в README, документации и интерфейсе.
- Проверки: `go test ./...`, `go vet ./...`, `python3 scripts/e2e.py` на отдельной тестовой БД.
